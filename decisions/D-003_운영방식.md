# D-003 운영 방식: 컨트롤 타워 + 실무 AI + 이 저장소

- 확정일: 2026-10-26
- 결정자: 사용자

## 결정

- **Claude = 컨트롤 타워:** 계획, 지시서, 검증·판정, 저장소 기록
- **GPT·Gemini = 실무:** 지시서 기반 세부 작업
- **이 GitHub 저장소 = 공동 기억장치:** 세 AI가 같은 진행판(STATUS.md)을 기준으로 움직인다

## 이유

1. **검토와 실행 분리:** 한 AI가 그럴듯하게 틀리는 것을 다른 쪽이 잡는다. (실제로 2026-10-26 GPT가 다른 AI의 과장을 여러 건 잡아냄)
2. **방향 고정:** 실무 대화에서는 질문마다 계획이 새로 짜이는 경향이 있었다 ("ComfyUI 필수" → "WAI 하나만" → "NovelAI로 시작"). 기준을 한 곳에 둔다.
3. **비용 절감:** 대화 전체 대신 진행판 + 지시서만 읽게 해서 사용량과 복사·붙여넣기 수고를 줄인다.

## 알려진 한계

- 컨트롤 타워는 **전달받은 것만 안다.** 다른 AI의 대화, NovelAI 화면, 생성 결과를 직접 볼 수 없다. (ChatGPT 공유 링크도 본문을 읽지 못함 — 실측)
- 컨트롤 타워라고 더 정확한 것은 아니다. 판정에도 확인 수준을 붙인다.
- GPT·Gemini가 GitHub raw 링크를 읽을 수 있는지 **미확인** → STATUS의 운영 테스트로 확인.

세부 규칙은 [RULES.md](../RULES.md).
