# D-002 ComfyUI·3D·기타 모델은 필요해질 때까지 보류

- 확정일: 2026-10-26
- 결정자: 사용자 승인 / 컨트롤 타워 제안 (GPT 검토와 일치)

## 결정

지금은 ComfyUI, 로컬 모델(NoobAI·Illustrious·WAI·Anima 등), Qwen·MOSS·MiniMax·Flux, 3D 변환 도구를 **도입하지 않는다.**

## 이유

- 지금 병목은 도구가 아니라 **"어떤 그림체를 원하는지"** 이다. 도구를 늘리면 비교 조건만 복잡해진다.
- 이전에 받은 조언 중 "무조건 ComfyUI", "8GB면 `--lowvram` 필수", "IP-Adapter+OpenPose면 동일 시트 완성", "WAI 하나만 쓰면 됨" 등은 **과장·오류가 섞여 있었다** ([handoffs/2026-10-26_gpt_ComfyUI조언검토](../handoffs/2026-10-26_gpt_ComfyUI조언검토.md)).
- 3060 Ti(8GB)가 입문 불가 사양은 아니므로, 필요해지면 그때 시작해도 늦지 않다.

## 재도입 조건

- NovelAI로 원하는 화풍이 안 나올 때
- 꼭 써야 하는 외부 LoRA(특정 작가 화풍)가 생겼을 때 → **그 LoRA의 지원 모델을 먼저 확인**하고 모델 선택
- 3D 단계(로드맵 4단계)에 진입할 때

## 주의

모델을 고를 때 "무료 공개"와 "상업 이용 가능"은 다른 조건이다. 라이선스를 따로 확인한다.
