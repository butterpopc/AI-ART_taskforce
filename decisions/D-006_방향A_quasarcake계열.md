# D-006 화풍 방향 A: quasarcake 계열(스케치풍 선 + 강한 명암·광택), 데포르메 제외

- 확정일: 2026-10-28
- 결정자: 사용자 ([EXP-02 결과 1](../experiments/EXP-02_StyleLab/RESULT_1_무작위200.md)의 상위 그림을 보고 고름)

## 사용자 판단 (원문 취지)

1. 후보 A(1·2위), B(6위), C(3·4위) 중 **A**를 고른다.
2. 데포르메(5위)는 귀엽고 호감은 가지만, 누가 그려도 기본은 하는 그림체라서 순위가 올라간 것이다. **전문 일러스트 그림체를 평가하는 작업에는 맞지 않다.** 우리가 만들려는 것은 낙서 같은 그림이 아니다.

## 결정

- 다음 탐색은 **quasarcake를 고정하고 짝이 되는 작가를 찾는 방식**으로 한다. 진화(상위 30% 전체 섞기)는 A와 B를 섞어 버리므로 당분간 쓰지 않는다
- 데포르메 계열은 방향 분석과 비교 대상에서 뺀다
- A의 특징(컨트롤 타워가 그림을 보고 정리): 스케치풍 거친 선, 빛과 그림자를 칼같이 나눈 강한 명암, 그림자 끝의 따뜻한 주황빛, 머리카락 광택, 반쯤 감은 눈의 성숙한 표정
- D-005("입체적 광택")는 **애니메 그림체 위에 얹은 광택과 강한 명암**으로 해석한다. 반실사는 하위권이었다

## 컨트롤 타워 보충

- 데포르메를 빼는 데는 목표상의 이유도 있다. 이 프로젝트는 기준 원화 → 다각도 설정화 → (장기) 3D로 가므로, 머리 크기와 몸 비율이 일정한 그림체가 필요하다. 2~3등신 데포르메는 설정화나 3D 기준으로 쓰기 어렵다(추정)
- 데포르메 자체가 낙서라는 뜻은 아니다. 나중에 이모티콘이나 굿즈용으로는 따로 쓸 수 있다

## 수정 (2026-10-28 밤) — 태그 지배력 문제

- 사용자 제보: 커뮤니티 평에 따르면 quasarcake 태그는 **다른 작가 그림체를 다 잡아먹어서 섞기용으로 비추천**이다 (출처 미확인 → [B-007](../briefs/B-007_조사_quasarcake유사작가.md)로 확인)
- 실험 데이터에도 같은 신호가 있다(실측 1건). 4명을 섞은 1위 조합이 quasarcake 단독(2위)과 거의 같은 그림이었다. 같은 조합에 가중치 1.6짜리 작가가 있었는데도 그랬다
- 따라서 **방향 A(그림의 특징)는 유지하고, quasarcake를 그대로 쓰는 것은 보류**한다
  1. 가중치를 낮춰도 덮는지 시험한다 (**0.4 / 0.6** — 아래 보충 참고)
  2. A 특징을 가진 다른 작가를 찾는다 (Gemini 조사 B-007)
- 이전 지시(`1.2::artist:quasarcake ::, __random__` × 20)는 **취소**한다. 짝이 묻혀 버려서 시험의 의미가 없다

### 보충 (같은 날) — 커뮤니티 평의 구체 내용

- 사용자 전달(여러 사람의 공통 의견이라고 함): "빛 표현은 정말 뛰어나지만 너무 강해서 다 잡아먹는다. **가중치 낮추기를 10번은 해야** 겨우 진정된다"
- 컨트롤 타워 확인: 웹 검색으로는 해당 글을 찾지 못했고, 아카라이브는 컨트롤 타워 환경에서 열리지 않는다 → **원문 미확인**. 다만 civitai 등에 quasarcake 그림체 LoRA가 여러 개 있을 만큼 많이 쓰이는 작가인 것은 확인했다
- "낮추기 10번"을 NovelAI 대괄호 규칙([FACTS N12](../FACTS.md): `[ ]` 한 겹 = ÷1.05)으로 계산하면 1.05¹⁰ ≈ 1.63이므로 **약 0.61배**다. 그래서 시험 가중치를 0.5/0.8에서 **0.4/0.6**으로 바꾼다 (0.8은 커뮤니티 기준으로 아직 덮는 구간)
