## 1. 무엇을 하는 도구인가 (README·코드 확인)

NovelAI 작가 태그 조합의 그림을 **둘씩 나란히 보여주고 마음에 드는 쪽만 고르게** 해서, Elo 점수로 순위를 매기는 Windows 앱.

| 단계 | 내용 |
|---|---|
| 준비 | API 키 입력, 작가 등록, 무작위 조합 생성 |
| 순위 결정 | 새 조합을 이진 탐색으로 순위표에 배치 (좌/우 선택) |
| 진화 | 상위 30% 조합의 작가·가중치를 섞고 바꿔 새 조합 생성 → 대결로 평가 |
| 다듬기 | 작가는 그대로, 가중치만 바꾼 변형과 대결. 조정 폭 ±0.3 → ±0.2 → ±0.1 |
| 완성 | 다른 시드 3개로 원본과 최종본 비교 → 최종 태그 복사 |

- **모든 그림을 시드 하나로** 그린다 → 우리 실험 원칙(조건 고정, 작가만 변경)과 같음
- 블라인드 모드: 작가명·점수를 가리고 그림만 보고 고름
- 프롬프트 뷰어: NovelAI PNG를 끌어놓으면 프롬프트·설정 표시

**프로젝트와의 관계:** 1단계(화풍 발견 → 작가 조합)를 거의 그대로 자동화한다. "고르는 눈"만 사용자 몫으로 남기는 구조라, 원하는 화풍을 말로 설명하기 어려운 현재 상황에 잘 맞는다 (추정).

## 7. 배포 파일 검증 (2026-10-27, 컨트롤 타워 — 내려받아 대조만, 실행 안 함)

대상: `NAI-Style-Lab.zip` (v4.1.5, 21,067,330 bytes, SHA-256 `6e0c0a4419bac7f88502d16f4e5c8f64669513fad6fae8aab362942bc3a3baa7`)

| 구성 | 대조 기준 | 결과 |
|---|---|---|
| 앱 코드 (`app/`, `web/`, `main.py`, `run.bat`, `README.md`) | GitHub 공개 소스 (커밋 8671c14, v4.1.5) | **내용 동일.** 차이는 Windows 줄바꿈(CRLF)뿐 |

**결론:** 배포 zip은 공개 소스 + 공식 Python + 공식 라이브러리로만 구성돼 있고, 수정된 부분은 설치 스크립트에 적힌 것뿐이다. 숨은 추가 코드는 발견되지 않았다.

**남는 위험 (추정)**
- 자동 업데이트: 앞으로의 새 버전은 이번 검증 대상이 아니다. 업데이트 알림이 떠도 바로 설치하지 말고 컨트롤 타워 확인 후 설치를 권장.

## 9. 폰 서버 모드 개조 (2026-10-28)

- 이유: 회사 PC 모니터에는 그림이 뜨면 안 되고, 집 PC를 계속 켜 두는 것도 어렵다(전기료, 가족이 끌 수 있음, 절전 모드). 그래서 **갤럭시 폰 한 대에서 Termux로 서버를 돌리고, 같은 폰의 Chrome으로 쓰도록** 개조했다

- 개조 내용: 창 없는 서버, 비밀번호 로그인, API 키 가림, 폰 화면 배치, PC 전용 기능과 자동 업데이트 차단. 원본 PC 창 앱은 바꾸지 않음

- **2026-10-28 방향 전환:** 갤럭시 S21(Android 15)에서 wake lock과 배터리 예외를 다 걸어도 Termux가 통째로 닫힘(실측, 사용자 보고). Termux는 targetSdk 28이라 삼성이 One UI 6부터 약속한 백그라운드 보장(Android 14 기준으로 만든 앱 대상)에서 빠지는 것으로 보임(추정, [dontkillmyapp](https://dontkillmyapp.com/samsung)).
