# AI-ART_taskforce

AI로 **사용자를 대표하는 페르소나 캐릭터**를 커스텀 화풍으로 만들고, 다각도 설정화 → 3D/움직이는 아바타까지 가는 프로젝트의 공용 저장소입니다.
여러 AI가 이 저장소를 **공동 기억장치**로 사용합니다.

---

## 🤖 처음 온 AI라면 이 순서로 읽으세요

1. **이 README** — 운영 구조와 역할
2. [`STATUS.md`](STATUS.md) — 지금 어디까지 왔는지 (진행판)
3. [`RULES.md`](RULES.md) — 인계·판정 양식, 작업 규칙 (**반드시 지킬 것**)
4. 사용자가 지정한 [`briefs/`](briefs/) 의 지시서 1개

필요할 때만 참고: [`FACTS.md`](FACTS.md) (검증된 사실), [`decisions/`](decisions/) (확정된 결정과 근거)

> 전체 대화 기록을 요구하지 마세요. 판단에 필요한 정보는 위 파일들에 있습니다.
> 위 파일과 다른 계획을 제안하려면 RULES.md의 "계획 변경 제안" 절차를 따르세요.

## 역할

| 역할 | 담당 | 하는 일 | 하지 않는 일 |
|---|---|---|---|
| **사용자** | 사람 | 그림 취향 판단, 최종 결정, AI 간 전달 | — |
| **컨트롤 타워** | Claude | 계획 수립, 지시서 작성, 실무 결과 검증·판정, 저장소 기록 | 실제 이미지 생성 |
| **실무** | GPT | 지시서에 따른 세부 작업 (프롬프트 변형, 결과 피드백, 문서 작업 등) | STATUS·decisions 핵심 수정, 계획 임의 변경 |
| **조사** | Gemini | 조사 지시서에 따른 자료 조사 → [조사 보고] 작성 | 취향 판단, 지시 범위 밖 조사, 계획 임의 변경 |

**저장소 권한:** GPT = 읽기·쓰기 (인계 요약을 `handoffs/`에 직접 올릴 수 있음) · Gemini = **읽기 전용** (조사 보고를 구글 드라이브에 올리거나 채팅으로 출력 → 사용자가 컨트롤 타워에 알림)

## 작업 순환

```
① 컨트롤 타워: briefs/ 에 지시서 작성
        ↓
② 사용자: 실무 AI에게 "README·STATUS·지시서 읽고 해줘" 전달
        ↓
③ 실무 AI: 작업 후 RULES.md의 [인계 요약] 양식으로 마무리
        ↓
④ 사용자: 인계 요약 + 결과 이미지를 컨트롤 타워에 전달
        ↓
⑤ 컨트롤 타워: [판정] → STATUS / decisions / handoffs 갱신
```

**조사 순환 (Gemini)**

```
① 컨트롤 타워: briefs/ 에 조사 지시서 작성
        ↓
② 사용자: Gemini에게 "README·STATUS·지시서 읽고 조사해줘" 전달
        ↓
③ Gemini: RULES.md의 [조사 보고] 양식으로 작성 → 구글 드라이브에 올림 (또는 채팅 출력)
        ↓
④ 사용자: 조사 보고를 컨트롤 타워에 전달 (붙여넣기 또는 파일)
        ↓
⑤ 컨트롤 타워: 핵심 주장 확인 → research/ 저장 → 검증된 사실은 FACTS.md로
```

## 폴더 구조

| 경로 | 내용 | 수정 권한 |
|---|---|---|
| `STATUS.md` | 진행판 (목표 / 현재 단계 / 확정 / 보류 / 다음 할 일) | 컨트롤 타워 |
| `RULES.md` | 운영 규칙과 양식 | 컨트롤 타워 (사용자 승인) |
| `FACTS.md` | 출처 확인된 사실 모음 | 컨트롤 타워 |
| `decisions/` | 확정된 결정 `D-번호_제목.md` | 컨트롤 타워 |
| `briefs/` | 실무 AI 지시서 `B-번호_제목.md` | 컨트롤 타워 |
| `handoffs/` | 실무 AI 인계 요약 `날짜_AI이름_주제.md` | 컨트롤 타워가 기록 |
| `experiments/` | 실험 기록 + 비교 합본 이미지 `EXP-번호_제목/` | 사용자·컨트롤 타워 |
| `prompts/` | 확정된 프롬프트 템플릿 `P-번호_제목.md` | 컨트롤 타워 |
| `research/` | Gemini 조사 보고 (컨트롤 타워 검증 표시 포함) `R-번호_제목.md` | 컨트롤 타워가 기록 |
| `tools/` | 외부 도구 검토 `T-번호_이름.md` | 컨트롤 타워 |
| `data/` | 실측 데이터 (예: 단부루 작가 지표 `data/artists/`) | GPT(지시서) · 컨트롤 타워 |
| `scripts/` | 데이터 재현 스크립트 | GPT(지시서) |

## 파일 직접 읽기 (raw 링크)

링크로 읽을 수 있는 AI는 아래 형식의 원문 주소를 쓰면 됩니다.

```
https://raw.githubusercontent.com/butterpopc/AI-ART_taskforce/main/STATUS.md
https://raw.githubusercontent.com/butterpopc/AI-ART_taskforce/main/RULES.md
https://raw.githubusercontent.com/butterpopc/AI-ART_taskforce/main/briefs/<파일명>
```

링크를 읽을 수 없다면, 사용자가 파일 내용을 붙여넣어 줍니다.
