# R-004 그림체 "활용성" 기준 — Gemini 요약 검토

- 출처: 사용자가 Gemini와 나눈 대화의 요약을 전달 (2026-10-28). 지시서 없이 나온 의견이라 [조사 보고] 양식은 아님
- 검토: 컨트롤 타워 (image-to-3D 도구 공식 문서와 대조)

## Gemini 요약 (원문 취지)

목표 = 개인 감상 + 놀이 + 게임 보조 자료 + 3D 캐릭터 변환·구동. 이 모두를 이으려면 "해부학 구조가 탄탄하고 선이 선명한 게임 컨셉 아트풍"을 골라야 한다.
1. 선화가 명확할 것 (빛에 선이 뭉개지지 않고 옷주름·장신구 경계가 확실 → 3D 참고, 누끼 작업에 유리)
2. 단정한 명암 (셀 셰이딩 / 반실사, 면 분할이 확실해야 AI 3D 도구가 입체감을 잘 인식)
3. 구도 안정성 (전신 정면이 잘 뽑히는 그림체)

## 검토

| 항목 | 판정 | 근거 |
|---|---|---|
| 1 선·경계 명확 | **맞음** | Scenario 문서: "Clear object boundaries: Well-defined edges help…" (문서 확인) |
| 2 명암 | **고쳐야 함** | 3D 변환 입력에는 그림자가 **약하고 고른** 그림이 좋다. Meshy 문서: "Avoid shadows and dark areas", "Use an evenly lit photo". Scenario 문서: "avoid extreme shadows". 강한 명암은 3D 텍스처에 그대로 구워져 남는다(추정). "반실사"는 사용자 순위에서 바닥이었다([EXP-02 결과 1](../experiments/EXP-02_StyleLab/RESULT_1_무작위200.md)) |
| 3 전신 정면 | **맞음 + 보충** | Meshy 문서: 정면, 직교에 가까운 시점 권장. 리깅(움직이게 만들기)용은 T자나 A자 자세 권장. 다각도 입력은 "similar lighting" (문서 확인) |
| 결론 "컨셉 아트풍을 골라야" | **순서를 바꿈** | 취향을 활용성 기준으로 대신 정하면 안 된다. 취향으로 후보를 좁힌 뒤, 활용성 시험을 관문으로 통과시킨다 |

## 핵심 충돌과 해결안

- 사용자 취향 A(강한 명암·광택, [D-006](../decisions/D-006_방향A_quasarcake계열.md))와 3D 입력 조건(고른 조명)이 정면으로 부딪힌다
- 해결안 (제안): **감상용과 기준용을 나눈다.** 같은 캐릭터를
  - 감상·놀이용: 취향 그림체 그대로(강한 빛)
  - 설정화·3D 기준용: 같은 그림체에 조명만 평평하게, 전신 정면 + A자 자세 + 단색 배경
  으로 따로 뽑는다. 그림체 후보는 **두 버전이 모두 잘 나오는지**로 마지막에 거른다
- 참고: 지금 네거티브의 Human Focus 목록에 `multiple views`가 들어 있다. 3단계(다각도 설정화)에서는 이 태그를 빼야 한다

## 반영

- 로드맵에 **"1.5 활용성 시험"** 추가: 취향 상위 후보 2~3개로 ① 전신 정면 ② 평평한 조명 버전을 뽑아, 그림체가 유지되는지와 몸이 깨지지 않는지 확인 → 통과한 것 중에서 기준 원화를 정함
- 지금까지의 실험은 전부 상반신(upper body)이었다. 전신에서 무너지는 그림체도 있을 수 있다(추정)
