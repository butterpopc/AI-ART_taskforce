## 판정 (컨트롤 타워)

**채택.** 8개 항목에 모두 답했고, 공식 저장소로 재확인한 핵심 사실(버전, 패키지 존재, 의존 관계)은 모두 맞았다. 다만 항목 4의 출처 링크는 주장과 맞지 않았다. **다음 조사부터는 주장마다 그 내용이 실제로 적힌 링크를 달 것.**

### 계획에 반영한 것

1. 설치 명령을 `pkg install python python-pillow unzip`으로 확정 (pip 경로는 쓰지 않음)
2. 기본 포트 8765 유지. 접속 주소는 `127.0.0.1`
3. 포트가 이미 쓰이면 서버가 다른 번호를 안내하도록 고침
4. 데이터를 프로그램 폴더 밖(`~/nsl-data`)에 두도록 고침 → 개조본을 새 판으로 바꿔도 데이터가 남음
5. 갤럭시 배터리 설정 2가지, 개발자 옵션, 인증서 오류 대처를 안내서 문제 해결 표에 넣음

안내서는 개조본 비공개 저장소의 `MOBILE.md`에 있음 (이 공개 저장소에는 올리지 않음. [T-001](../tools/T-001_nai-style-lab.md)의 라이선스 메모 참고).

### 남은 확인 (실제 폰에서만 가능)

- 갤럭시에서 설치부터 접속까지 실제로 되는지 → 사용자가 처음 설치할 때 확인
- 화면을 끄고 오래 두어도 서버가 살아 있는지
