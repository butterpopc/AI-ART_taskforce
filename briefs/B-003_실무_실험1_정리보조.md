# B-003 실무 지시서 — 실험 1 결과 정리 보조

- 작성: 컨트롤 타워 · 2026-10-26
- 담당: **GPT (실무)**
- 관련: [B-001](B-001_실험1_작가비교.md) 실험 1, [EXP-01](../experiments/EXP-01_작가비교/README.md)
- 시작 시점: 사용자가 실험 1 이미지 6장을 GPT에게 줄 때 (2026-10-26 개정: 4장 → 6장)

## 목적

사용자가 실험 1 결과를 정리하는 수고(합본 만들기, 기록 표 채우기)를 GPT가 대신해서, 사용자는 **그림을 보고 고르는 일**에만 집중하게 한다.

## 할 일

### 1. 3×2 합본 이미지 만들기

- 입력: 사용자가 준 6장 (작가 A~F)
- 배치: 윗줄 A(ciloranko) · B(atdan) · C(lam) / 아랫줄 D(puuzaki puuna) · E(ishikei) · F(yd (orange maru)) — 사용자가 다른 순서를 말하면 그에 따름
- 각 칸 위나 아래에 **칸 문자 + 작가 태그**를 읽기 쉽게 표기
- 원본 비율 유지, 칸 크기 통일. 긴 변 2048px 이하, 파일 5MB 이하
- 저장: `experiments/EXP-01_작가비교/grid.png`

### 2. EXP-01 기록 표 채우기

`experiments/EXP-01_작가비교/README.md`에서:
- 조건의 **시드** 값 (사용자에게 받거나, 이미지 메타데이터에서 확인 가능하면 그 값. 출처 표시)
- 표의 **자동완성** 칸 (사용자에게 들은 대로: 뜸 / 안 뜸 / 결과 변화 약함)
- 표의 **사용자 반응** 칸 — 사용자가 한 말을 **그대로** 옮긴다. 요약·해석 금지
- `상태`를 "결과 수령, 판정 대기"로 변경
- `판정` 섹션은 **비워 둔다** (컨트롤 타워 몫)

### 3. 객관적 차이 기술

같은 README에 `## 차이 기술 (GPT)` 섹션을 만들고, 6장의 차이를 항목별로 짧게 적는다.
- [D-005](../decisions/D-005_취향방향.md)에 따라 **광택·입체감(하이라이트, 반사광, 그라데이션 단계)** 과 **인상(성숙함/귀여움 쪽)** 항목을 추가한다. 이 역시 판단 없이 관찰만.
- 항목: 눈 표현 / 선(굵기·색) / 채색 방식 / 명암 / 얼굴·신체 비율 / 전체 색감
- **어느 쪽이 좋은지 판단 금지.** 사용자 취향을 유도하는 표현("더 예쁨", "추천")도 금지
- 확신이 없는 관찰은 `추정`으로 표시
