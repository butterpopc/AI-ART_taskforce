# B-004 실무 지시서 — 취향 자료 분석 (NovelAI 없이 하는 1단계 보조)

- 작성: 컨트롤 타워 · 2026-10-26
- 담당: **GPT (실무)**
- 배경: 사용자가 근무 중이라 NovelAI(실험 1)를 돌릴 수 없음. 그동안 **사용자가 이미 좋아하는 그림**에서 취향 단서를 뽑아둔다.
- 관련: [B-001](B-001_실험1_작가비교.md) 실험 1, [B-002](B-002_조사_작가태그.md) Gemini 작가 태그 조사

## 하지 않는 것 (중요)

- **GPT 이미지 생성으로 실험 1을 대신하지 않는다.** 이유:
  1. 결과가 NovelAI V4.5 Full의 화풍과 다르므로 실험 1의 대체가 되지 않는다 ([D-001](../decisions/D-001_V4.5Full로_화풍탐색.md)) — 추정
  2. 특정 작가 이름으로 화풍을 흉내 내는 생성은 거절되거나 부정확할 수 있다 — 추정
- 작가 추천·다음 실험 설계 금지 (컨트롤 타워·Gemini 몫)
- **사용자 취향을 대신 판단하지 않는다.** "이게 더 좋아 보인다" 같은 유도 금지

## 사용자가 할 일 (휴대폰으로 가능, 5분)

- 평소 "그림체 좋다"고 느낀 그림 **5~10장**을 GPT에게 보낸다. 링크 또는 이미지
- 작가·작품이 달라도 됨. 이유 설명 불필요
- 특정 부분만 좋으면 한 단어만 붙인다: "눈", "색", "선" 등

## GPT가 할 일

### 1. 그림별 특징 기술

각 그림마다 아래 항목을 짧게, 객관적으로 기술한다.
- 눈 표현 (크기, 하이라이트 수, 속눈썹, 홍채 표현)
- 선 (굵기, 색, 강약)
- 채색 (셀 / 부드러운 그라데이션 / 두껍게 칠함 등)
- 명암 (대비 강도, 그림자 색감)
- 얼굴·신체 비율 (얼굴형, 머리 대 몸 비율)
- 전체 색감 (채도, 따뜻함/차가움)
- 사용자가 붙인 한 단어가 있으면 그 부분을 더 자세히

### 2. 공통점 정리 = 취향 후보

- 여러 그림에 반복해서 나타나는 특징을 **"취향 후보"** 로 3~6개 정리
- 각 후보마다 몇 장에서 나타났는지 표기 (예: 7장 중 5장)
- 서로 상충하는 특징이 있으면 그대로 적는다 (예: 두꺼운 선 3장 / 가는 선 4장)
- 그림 속 캐릭터가 예뻐서인지, **표현 방식**이 좋아서인지 구분이 필요해 보이면 사용자에게 질문 1~2개를 남긴다

### 3. 태그 후보 매핑 (추정)

취향 후보를 Danbooru 계열 화풍 태그로 옮길 수 있으면 후보를 적는다 (예: `thick outlines`, `flat color`). **전부 `추정`으로 표시.** 실제 NovelAI 반응은 나중에 실험으로 확인한다.

### 4. 기록

`experiments/EXP-00_취향자료/README.md` 에 위 1~3을 저장하고, `handoffs/YYYY-MM-DD_gpt_취향자료분석.md` 에 [인계 요약]을 남긴다.

- ⚠️ **공개 저장소이므로 다른 작가의 그림 파일은 올리지 않는다.** 그림은 번호(그림 1, 그림 2…)와 출처 링크(사용자가 링크로 줬다면)만 적는다.
- 그림 출처를 모르면 "출처 미상"으로 적는다.

- [ ] EXP-00 기록 + 인계 요약
