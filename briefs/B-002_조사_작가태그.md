# B-002 조사 지시서 — 작가 태그 조사 (→ R-001)

- 작성: 컨트롤 타워 · 2026-10-26
- 담당: **Gemini (조사)**
- 제출: RULES.md 2-1의 **[조사 보고]** 양식으로 채팅에 출력 (보고 번호 R-001)
- 관련: [B-001](B-001_실험1_작가비교.md) 실험 1 — 이 조사는 실험 1과 **병행**하며, 실험 1을 기다리게 하지 않는다.

## 배경

실험 1에서 NovelAI V4.5 Full에 작가 태그 4개를 넣어 화풍을 비교한다. 그런데 태그의 정확한 표기와, 모델이 그 작가를 얼마나 잘 아는지가 모두 미확인이다 ([FACTS.md](../FACTS.md) "작가 태그 인식 여부").
NovelAI는 Danbooru 태그 체계를 쓰므로, Danbooru 기준 정보를 확보하면 실험 설계가 정확해진다.

## 조사 항목

### 1. 후보 4명의 Danbooru 정보

대상: `ciloranko`, `atdan`, `lam (ramdayo)`, `puuzaki puuna`

각 작가마다:
- Danbooru의 **정확한 작가 태그 문자열** (밑줄·괄호 포함 원문 그대로)
- 다른 이름(alias) / 다른 표기
- **게시물 수** (조사일 기준)
- 화풍의 객관적 특징 (선 굵기, 채색 방식, 명암, 눈 표현, 신체 비율 등). **좋고 나쁨 평가 금지**
- Danbooru 태그 검색 링크

### 2. puuzaki puuna와 특징이 비슷한 작가 4~6명

- 무엇이 비슷한지 (예: 눈 표현, 색감 등) 구체적으로
- 각 작가마다 항목 1과 같은 정보 (태그 문자열, 게시물 수, 특징, 링크)
- 게시물 수가 너무 적은 작가(예: 100 미만)는 모델이 잘 모를 가능성이 있으니 표시 (이 기준은 추정)

### 3. NovelAI V4.5의 작가 태그 인식 관련 공개 정보 (있으면)

- 공식 문서나 커뮤니티에 "어떤 작가 태그가 잘 먹히는지", "인식 여부 확인 방법"에 대한 정보가 있는지
- 출처마다 신뢰도 표시 (공식 / 커뮤니티 / 개인 블로그 등)
- 없으면 "찾지 못함"으로 적는다

## 제약

- **링크는 실제로 연 것만.** 못 연 링크는 `확인 못 한 것`에 적는다.
- 숫자(게시물 수 등)는 조사일과 함께 적는다.
- 작가 개인 신상은 조사하지 않는다. 활동명·작품 경향만.
- 이미지 자체를 재현하거나 붙이지 않는다. 링크만.
- 한국어로 작성.
