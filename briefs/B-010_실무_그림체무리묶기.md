- 담당: **GPT (실무)** — 코드 작성·시험. 실제 PC 설치는 컨트롤 타워가 한다
- 대상 저장소: **비공개** `butterpopc/nai-app-project` (Style Lab 개조본). 이 공개 저장소에는 코드를 올리지 않는다
- 근거: [R-005](../research/R-005_그림판별자동화.md)(CSD 화풍 임베딩), 사용자 결정(2026-10-31)

## 왜 이 방식인가 (컨트롤 타워 판단)

- 사용자 앞에 단독 작가 그림 약 5,000장이 쌓였다. 하나씩 대결로 배치하면 2만 번 넘게 골라야 한다
- "좋아요 예시와 비슷한 순으로 정렬"은 쓰지 않는다. **기존 순위 자체가 검증되지 않아서**(대결 4~8번, 시드 1개) 그걸 정답으로 삼으면 어긋날 수 있다는 사용자 지적이 맞다
- 대신 **예시 없이 그림체가 비슷한 것끼리 무리를 짓는다.** 사용자는 무리마다 대표 몇 장만 보고 "통째로 싫어요"를 하거나, 끌리는 무리만 열어 본다. 기계는 "서로 닮았다"만 정리하고, 좋고 싫음은 전부 사용자가 정한다
- 기존 도구(FiftyOne, fastdup, digiKam 등, R-005 4번)는 Style Lab의 표시 방식(Elo)과 연결되지 않아 결과를 다시 옮겨 적어야 한다. 그래서 **Style Lab 서버 안에 화면을 하나 붙인다**

## 사용자 쪽 규칙 (이미 정해져 있음)

- Style Lab에서 **Elo 0 = 싫어요, Elo 20000 이상 = 좋아요**. 앱 기존 기능 `POST /api/combos/elo {ids, elo}`로 바꾼다
- 단독 그림 중 **가중치 1.0인 것만** 대상이다(`style`이 `1.0::artist:<태그> ::` 한 개). 0.8·0.9 등으로 그린 예전 그림은 같은 작가의 1.0 그림이 있으면 제외한다

## 만들 것 (2부분)

### A. `tools/cluster/cluster_styles.py` — 무리 계산 (집 PC GPU에서 실행)
- 입력: `data/state.json`의 `combinations`(id, style, elo, image_file), `data/images/*.png`
- 대상: 위 규칙의 단독 1.0 그림 중 **아직 표시 안 된 것**(Elo가 0도 아니고 20000 이상도 아님). 대결로 이미 자리 잡은 것도 포함
- 임베딩: **CSD-ViT-L**(화풍 전용). 받을 수 없거나 실패하면 CLIP ViT-L/14로 대체하고 그 사실을 출력에 적는다. 캐시(`data/cluster_cache.npz`, 파일 이름+수정 시각 기준)로 다음 실행은 새 그림만 계산
- 무리 짓기: L2 정규화 후 k-means. 무리 수 기본 **60**(옵션으로 변경). 무리마다 중심에 가까운 대표 **4장** + 무작위 **2장**(다양성 확인용)
- 출력: `data/clusters.json` = `{generated, model, k, clusters: [{id, size, reps: [combo_id...], members: [combo_id...]}]}`. 무리는 크기가 큰 순서
- 실행기: `tools/cluster/cluster_styles.bat`(더블클릭). **ComfyUI 환경을 망가뜨리지 않도록 별도 가상환경**(uv 권장)을 쓰고, 첫 실행 때 설치. GPU가 없으면 CPU로(느리다고 안내)

### B. 서버 화면 `/clusters` — 무리 보고 표시하기 (`server.py`에 추가)
- 로그인한 사용자만(기존 인증·Host·출처 검사 그대로). `data/clusters.json`을 읽어 보여 준다. 파일이 없으면 "먼저 cluster_styles.bat을 실행하세요"
- 첫 화면: 무리 카드 목록. 카드마다 대표 6장 썸네일(`/thumb/<image_file>`), 무리 크기, 아직 표시 안 된 수, 버튼 **[통째로 싫어요]**, **[열기]**
  - [통째로 싫어요]: 확인 창 → 그 무리에서 **표시 안 된 것 전부** Elo 0. 이미 좋아요(20000)인 것은 건드리지 않음
- [열기]: 무리 안 전체 썸네일 그리드. 탭으로 여러 장 선택 → **[좋아요]**(Elo 20000) / **[싫어요]**(Elo 0). 작가 태그 표시. 길게 누르면 원본(`/img/…`) 새 탭
- 표시는 반드시 기존 `/api/combos/elo` 경로(엔진 함수)를 거친다. state.json을 직접 고치지 않는다
- 화면은 폰 기준(412px 폭)으로 먼저 맞추고 PC에서도 깨지지 않게. 원본 앱 화면(index.html)과 분리된 별도 페이지로 만든다
- 홈 화면이나 메뉴에서 이 페이지로 가는 링크 하나
