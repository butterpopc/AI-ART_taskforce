# B-006 실무 지시서 — 폰 서버 모드 개조본 코드 검토 (독립 점검)

- 작성: 컨트롤 타워 · 2026-10-28
- 담당: **GPT (실무)**
- 배경: NAI Style Lab을 갤럭시 폰(Termux)에서 서버로 돌리고 같은 폰의 Chrome으로 쓰도록 컨트롤 타워가 개조했다 ([T-001 9절](../tools/T-001_nai-style-lab.md), [R-002](../research/R-002_Termux환경.md)). 코드를 쓴 쪽이 자기 코드를 검사하면 놓치는 것이 생기므로, **작성에 참여하지 않은 GPT가 따로 점검**한다.
- 대상: 사용자 계정의 **비공개** 저장소 `nai-app-project` (커밋 `fd2f677` 이후).
  - 접근 방법은 둘 중 하나: ① 사용자가 ChatGPT의 GitHub 연결에서 이 저장소 읽기를 허용하거나, ② 사용자가 저장소 zip을 채팅에 첨부한다.
  - 접근이 안 되면 추측으로 검토하지 말고 "접근 불가"로 보고한다.

## 읽을 파일

| 파일 | 내용 |
|---|---|
| `server.py` | 새로 만든 서버 (핵심 검토 대상) |
| `web/js/api.js`, `web/js/ui.js` | 서버 모드 호출 경로, 터치 선택 |
| `web/mobile.css` | 폰 화면 배치 |
| `start.sh`, `MOBILE.md` | 실행 스크립트, 사용자 안내서 |
| `app/bridge.py` | 원본 코드. `App.call`의 경로 목록과 `resource()`를 대조하는 데만 사용 |

## 점검 항목

1. **로그인 우회**: 로그인하지 않은 상태에서 그림·썸네일·설정·`/rpc`에 닿는 경로가 있는지 (`/static/`, `/img/`, `/thumb/`, URL 인코딩, `..`, 대소문자, 쿼리 문자열 등)
2. **경로 탈출**: `/img/`, `/static/`으로 데이터 폴더나 프로그램 폴더 밖의 파일을 읽을 수 있는지
3. **요청 위조(CSRF)**: 다른 사이트가 폰 Chrome을 통해 `/rpc`나 `/login`을 대신 호출할 수 있는지 (SameSite=Strict 쿠키 + `X-NSL` 헤더 조합이 충분한지)
4. **비밀번호·세션**: PBKDF2 저장, 세션 토큰 생성과 저장(해시), 비교 방식(시간 차 공격), 5회 실패 시 60초 잠금이 우회되는지, 로그아웃 처리
5. **API 키 노출**: 설정 응답, 오류 메시지, `app.log`, 그 밖의 응답 어디로든 키 원문이 나가는지. 가림 문자열(`••••`)이 저장 요청으로 돌아왔을 때 기존 키가 지워지거나 덮어써지지 않는지
6. **막은 기능 누락**: `app/bridge.py`의 `App.call` 경로 가운데 서버 모드에서 위험하거나 의미 없는데 `BLOCKED`에 빠진 것이 있는지 (파일 대화상자, PC 경로 노출, 업데이트, 프로그램 종료 등)
7. **동시 실행·저장**: 여러 요청이 동시에 들어올 때(ThreadingMixIn) 원본 엔진 잠금과 충돌하는지, Ctrl+C로 끌 때 저장이 빠지는 경우가 있는지, 잠금 파일(`.server-mode.lock`) 처리가 맞는지
8. **PC 창 앱 영향**: 개조가 원본 PC 창 앱(`main.py`) 동작을 바꾸는 부분이 있는지 (`api.js` 데스크톱 경로, `ui.js` 변경)
9. **안내서 정확성**: `MOBILE.md`의 명령어가 `start.sh`·`server.py`의 실제 동작과 맞는지

## 하지 않는 것

- **코드를 직접 고치거나 커밋하지 않는다.** 발견한 문제는 보고만 한다(수정은 컨트롤 타워가 함)
- 코드나 그 일부를 **공개 저장소(AI-ART_taskforce)에 붙여넣지 않는다.** 원본 라이선스가 없어 비공개로만 쓰기로 했다. 보고서에는 파일명, 줄 번호, 짧은 설명만 쓴다
- API 키, 비밀번호, `data/` 폴더 내용을 요구하거나 다루지 않는다
- 기능 추가나 디자인 개선은 제안하지 않는다 (이번 범위는 결함 찾기)
