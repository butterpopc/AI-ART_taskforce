# B-010 실무 지시서 — 그림체 정렬 도구 만들기 (사용자 피로 줄이기)

- 작성: 컨트롤 타워 · 2026-10-29
- 담당: **GPT (실무)** — 코드 작성·시험. 실제 PC 설치·실행은 컨트롤 타워가 한다
- 근거: [R-005](../research/R-005_그림판별자동화.md) 추천안
- 목적: NovelAI Style Lab으로 뽑은 그림 수천 장을 **사용자 취향과 비슷한 순서로 정렬**해서, 사용자는 위쪽 일부만 보게 한다. 마지막 판단은 사람이 한다

## 입력 (사용자 PC의 Style Lab 설치 폴더)

- `data/state.json`: 키 `combinations` = 조합 목록. 각 조합의 `id`, `style`(예: `1.0::artist:lack ::`), `elo`, `placed`, `image_file`(PNG 이름)
- `data/images/<image_file>`: 원본 PNG(832×1216)
- `data/thumbs/<이름>.webp`: 썸네일(최대 440×760). HTML 갤러리에는 이걸 쓴다
- **API 키 파일(`data/api_key.txt`)과 `data/remote.json`은 열지도 복사하지도 않는다**

## 좋아요·싫어요 표시 규칙 (앱 기능만으로 표시하게 정함)

- 사용자는 Style Lab 갤러리에서 여러 장을 고른 뒤 "Elo 수정"으로 표시한다
  - **Elo 0 = 싫어요**
  - **Elo 20000 이상 = 좋아요**
  - 그 밖 = 미분류(정렬 대상)
- 처음 시작용 예시를 별도 파일로도 받는다: `likes.txt`, `dislikes.txt`(이미지 파일 이름 한 줄에 하나). 컨트롤 타워가 EXP-02 결과로 채워 둔다

## 만들 것

1. `sort_styles.py`
   - 임베딩: **CSD-ViT-L**과 **CLIP ViT-L/14**. 이미지마다 계산해 캐시(`sort_cache.npz`, 파일 이름+수정 시각 기준). 다시 돌리면 새 그림만 계산
   - 점수: (a) 좋아요 평균 − 싫어요 평균 방향과의 내적. (b) 좋아요·싫어요가 각각 10장 이상이면 로지스틱 회귀 확률도 계산. 두 모델·두 점수는 표준화해서 평균
   - 흑백 판별(채도 기반)로 `흑백 의심` 표시만 한다(자동 삭제 금지)
   - 출력:
     - `ranked_gallery.html`: 미분류 그림을 점수 순으로. 썸네일, 순위, 점수, 작가 태그, 이미지 파일 이름. 오프라인에서 열리고, 썸네일은 상대 경로로 불러온다. 한 페이지가 너무 무거우면 나눈다
     - `ranked.csv`: 같은 내용
2. `sort_styles.bat`: 더블클릭 한 번으로 실행. 처음 실행 때 필요한 것을 설치하고, 끝나면 HTML을 연다
3. `SORT_STYLES.md`: 한국어 사용 안내(코딩 경험 없는 사용자 기준)

## 조건

- 환경: Windows, RTX 3060 Ti 8GB, ComfyUI 설치됨(설치 방식은 미확인). **ComfyUI 환경을 망가뜨리지 않는다.** 별도 가상환경(uv 등)을 기본으로 하고, 그 이유와 디스크 용량(PyTorch 등)을 안내서에 적는다. GPU가 없거나 CUDA가 안 되면 CPU로 돌아가게(느리다고 안내)
- 모델 다운로드 출처, 버전, 라이선스를 안내서에 적는다. 모델 가중치 파일은 저장소에 올리지 않는다
- 사용자 그림이나 state.json을 저장소에 올리지 않는다. 시험은 가짜 그림(합성 이미지)과 가짜 state.json으로 한다
- 성인 등급으로 거르는 기능은 넣지 않는다([RULES 8](../RULES.md))
- 코드 위치: 이 저장소 `tools/sort_styles/`
